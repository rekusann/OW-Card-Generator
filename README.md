# Card-generator
## 使い方

左側のフォームで各項目を編集する → 画像サイズを指定してpng出力する

入力内容はブラウザ（localStorage）に自動保存される。「入力内容をリセット」で初期状態に戻る。

## ヒーロー一覧（text/heroes.txt）

- 1行に1ヒーロー。`<TANK>` のような行はロールの見出し
- 画像ファイル名は表示名のスペースを `-` に置き換えたもの（例：`Junker Queen` → `img/Junker-Queen.png`）
- ファイル名を変えたいときは `表示名 | ファイル名` と書く（例：`Torbjörn | Torbjorn`）
- `img/` に画像がないヒーローは、背景キャラの選択肢で「画像未登録」と表示され選べない
